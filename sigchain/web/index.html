关于 SignalChain

SignalChain 是一个本地运行的 DSP（数字信号处理）信号链工作台，面向嵌入式与光电系统开发中的常见需求：ADC 采样、抗混叠滤波、数字滤波、频谱分析，以及 SINAD / ENOB / THD / SFDR / IMD 等指标的测量。

全部核心算法（基-2 FFT、窗函数、FIR/IIR 滤波器设计、双线性变换、量化噪声建模）均为纯 Python 标准库实现，零第三方依赖，可直接阅读与教学。

能力一览

  • 手写 FFT：基-2 迭代 Cooley–Tukey，含位反转、窗函数（Hann/Hamming/Blackman/Blackman-Harris/Kaiser/Flattop）
  • 滤波器设计：FIR（窗函数法）与 IIR（Butterworth 双线性变换），支持低通/高通/带通/带阻
  • ADC 建模：位宽、参考电压、偏置、增益误差、抖动、dither
  • 频谱指标：SINAD、SNR、ENOB、THD、SFDR、IMD3
  • 采样理论：混叠演示、抗混叠抽取、过采样插值

典型工作流

  1. 生成一个信号（正弦 / 扫频 / 噪声）
  2. 经过 ADC 量化（选择位宽）
  3. 设计滤波器去除噪声 / 干扰
  4. 测量滤波前后的 SINAD、ENOB、THD
